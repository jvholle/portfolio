\# Weather Data Prediction Tool



\## Process



Extract data from a public weather data API and use the time series data with SciKit-Learn Library to predict future temperatures and record weather anomalies. The predictions are generated by training a regression model with the temperature data and generating predictions from the predict method. Anomalies are generated from the Local Outlier Function with the same library.



Flask web server is used for the user interface and a script orchestrates the ETL process of extracting data from the API, transforming the dataset, loading the data into an CSV file, and generating the ML process.
